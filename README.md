# Inditech Phone — White-Label Device Financing & MDM Platform

B2B2C multi-tenant SaaS that turns Android smartphones into self-enforcing loan collateral. Lenders,
telcos and retailers issue device loans; the platform enrolls each handset as a Device Owner, keeps it in
sync with the loan ledger and progressively restricts it (Grace → Soft Lock → Hard Lock) when repayments
are missed — and releases it when the loan is paid off.

## End-to-end flow

1. **Tenant onboarding** — super-admin calls `POST /api/v1/platform/tenants` (branding config + first admin).
2. **Point of sale** — an agent registers the borrower and books a loan against the phone's IMEI
   (`POST /api/v1/admin/loans`), then shows the provisioning QR (`POST …/provisioning-tokens`).
3. **Provisioning** — factory-fresh phone scans the QR (or receives it via Zero-Touch); the DPC becomes
   Device Owner, enrolls (`POST /api/v1/devices/enroll`), downloads tenant branding and applies
   hardening policies before setup can complete.
4. **Servicing** — the DPC heartbeats every 15 minutes; payments arrive through signed provider webhooks
   and update the ledger; the overdue evaluator escalates delinquent devices; commands reach the phone over
   FCM + MQTT in seconds and are acknowledged.
5. **Payoff** — the final repayment releases the device: all restrictions are lifted and Device Owner is
   relinquished.

## Quick start

```bash
# backend
cd backend && cp .env.example .env && docker compose up -d postgres redis mosquitto
npm install && npm run migrate && npm run dev     # + `npm run dev:worker` in another shell
npm run seed                                      # demo tenant, loan & QR payload

# mobile
cd mobile && ./gradlew assembleDebug
```
